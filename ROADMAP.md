# Roadmap

Ouroboros Timelines is in the 0.x prerelease series. Native `.ob` files use format version 1; the plugin version tracks ongoing development and is not a claim of API or file-format stability. Changes in each release are listed in the [changelog](CHANGELOG.md). Releases before 1.0 are published as draft prereleases for testing; a stable 1.0 release will be announced separately.

Current release: **0.1.2** (prerelease).

## Next

- **Sub-timelines.** Timelines linked into a tree, like continent, nation, and city, or universe, galaxy, and planet, and a timeline branched for an alternate history. Parent events will show as context in the timelines below them, and important events will rise into the timelines above.

  Version 1 of the [file format](docs/dev/file-format.md) already reserves the fields this needs, so your timelines won't need converting.
